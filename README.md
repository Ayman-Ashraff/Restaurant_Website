# 🍽️ Restaurant Website

A modern restaurant landing page built with HTML and CSS.

## 🔗 Live Demo
https://ayman-ashraff.github.io/Restaurant_Website

## 🛠️ Built With
- HTML5
- CSS3
- Font Awesome Icons

## 💡 Features
- Responsive navigation bar with upper and lower sections
- Hero section with call-to-action buttons
- Book a Table and View Menu options
- Clean and modern restaurant branding

## 🚀 How to Run
Clone the repo and open index.html in your browser, or visit the live demo link above.
